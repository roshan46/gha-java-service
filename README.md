# Java CI exercise

Use Java 21 and Maven 3.9.16. Run `mvn -B -ntp verify`, then `java -cp target/gha-service-1.0.0.jar study.App`; the result should be 5.

The workflow adds Checkstyle, JUnit reports, dependency scanning, and source-revision metadata. Read Lab 5 in the study module for failure drills and completion criteria. No service is deployed by this repository.
